# Journey to the West 章节题目打印工具

这是一个零依赖的本地可视化打印工具。
它会读取同目录中的 `4-journey-to-the-west-quiz.md` 题库。

## 启动并打开网页

1. 双击 `start.command`。
2. 系统会打开一个终端窗口并启动本地服务。
3. 浏览器通常会自动打开操作页面。
4. 如果浏览器没有自动打开，请复制终端里显示的地址。
5. 地址格式类似 `http://127.0.0.1:62206`，每次启动端口可能不同。
6. 不要直接双击 `index.html`，否则浏览器可能无法读取题库文件。

也可以在终端进入本目录后手动启动：

```bash
python3 server.py
```

关闭启动时出现的终端窗口即可停止本地服务。
在终端里启动时，也可以按 `Ctrl+C` 停止服务。

## 使用方法

1. 从左侧选择要打印的章节。
2. 选择“学生版”或“教师版”。
3. 按需打开或关闭“显示日期”，关闭后会保留 Date 横线供手写。
4. 默认使用“随机排列”，也可以切回“保持原顺序”。
5. 点击“打印本章”。
6. 如需批量打印，在左侧勾选多个章节，再点击“打印所选”。

随机模式下可以点击“重新随机”生成另一组选项顺序。
教师版会在题目后附上答案页。
打印窗口中也可以选择“存储为 PDF”。
